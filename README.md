# Portal do Aluno (PHP)

Cadastro simples de aluno (nome, e-mail, idade) com validação e sessões. Sem banco de dados ou frameworks.

## Estrutura
```
index.php · cadastro.php · processar_cadastro.php · resultado.php · logout.php
includes/ → cabecalho.php · rodape.php · funcoes.php
```

## Executar
```bash
php -S localhost:8000
```
Acesse http://localhost:8000/index.php (ou coloque a pasta no `htdocs` do XAMPP).

Testes: veja `TESTES.md`.
